# Driver Mobile Design System

## Tasarım karakteri

- Endüstriyel
- Modern
- Sade
- Yüksek okunabilirlik
- Operasyon odaklı

## Layout

- 16dp genel yatay padding
- 12–16dp card gap
- ana CTA yüksek ve full width
- önemli kartlarda gereksiz dekorasyon yok

## Primary CTA

Ana operasyon butonu:
- ekranın alt yarısında kolay erişilebilir
- full width
- güçlü label
- icon + text mümkün

Örnek:
`✓ SEFERİ KABUL ET`

## Typography

Şoför için küçük typography'dan kaçın.
Trip no secondary olabilir; route ve action daha belirgin.

## Status

Örnek:
- Assigned
- Accepted
- In Progress
- Break
- Delayed
- Finished
- Offline/Pending

Renk + icon + text birlikte.

## Home quick menu

Önerilen 2x2 büyük kart:

[ SEFERLER ] [ EVRAKLAR ]
[ ÜCRETLER ] [ SORUN BİLDİR ]

## Bottom nav

- Ana Sayfa
- Seferler
- Evraklar
- Profil

## Empty states

"Sefer yok" ekranı boş görünmemeli:
- `Şu anda atanmış seferiniz yok.`
- sync zamanı
- vardiya bilgisi
- planner contact secondary

## Driving safety

Uygulama aktif sürüş sırasında yoğun etkileşimi teşvik etmemelidir.
Uzun form ve karmaşık seçimler minimumda tutulmalıdır.
